# 评估理解

评估用户答案或复述，指出正确部分、关键误差和下一步修正方向。没有用户作答时不得主动考核。

提取用户主张并确定材料、题目或定义中的评估标准。证据不足时最多补一次 `reader_search_passages` 或 `reader_read_passage`。分别判断正确内容、部分正确、概念混淆、缺失条件和无证据推断，并解释错误原因和更准确表达。

没有明确量表时不给伪精确分数，不评判人格、智力或稳定能力。输出总体判断、正确部分、需修正部分、原因、更准确表达和一个最小检查问题。
