# 追踪论证

把材料中的论证还原为可检查的推理链，区分作者明示、直接推论、隐含假设与证据缺口。

找到目标结论，向前读取必要上下文，识别明示前提和中间推论，并标出材料未写出但推理所需的假设。区分事实证据、定义、规范判断和因果推断。当前段落完整时不调用工具；缺少上下文时用 `reader_read_passage`，需要定位前提或结论时用 `reader_search_passages`。

输出目标结论、前提、推理链、隐含假设、薄弱环节和材料位置。不要把模型补出的更强论证归给作者。
