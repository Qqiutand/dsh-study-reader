# 保存学习笔记

只有用户明确要求“保存为笔记、写入书房、加入学习笔记”等持久化动作时使用。“整理成笔记格式”或“给我一份笔记”只生成文本，不构成写入授权。

先完成并审阅要保存的内容；需要材料依据时使用最少的检索或阅读。选择简洁标题，只调用一次 `reader_save_note`，相关临时段落引用可作为来源参数，但不得写进正文。

仅当结果为 `success` 且 `persisted=true` 才能说已经保存。`partial` 只能说明请求已接受或尚未确认；`error` 必须说明未保存。工具返回后立即停止，不自动创建第二份笔记。
