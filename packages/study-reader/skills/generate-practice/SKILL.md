# 生成练习

只有用户明确要求练习题、测验、自测、问答卡或证明练习时使用。

确认范围、数量、难度和题型。当前材料足够时直接生成；章节任务可用 `reader_get_outline`，缺少具体知识点时最多补一次 `reader_search_passages` 或 `reader_read_passage`。每道题应对应回忆、理解、应用、分析或推导目标，避免只替换名词的重复题。

用户要求自测时先只给题目等待作答；否则答案与题目清楚分隔，并说明关键依据。不要自动保存题目，也不要为了增加数量扩展到未要求的材料。
