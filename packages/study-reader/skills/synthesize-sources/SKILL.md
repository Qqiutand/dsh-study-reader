# 跨文献综合

围绕明确问题综合多个文献的观点、证据、共识、冲突和空白，而不是逐篇机械摘要。

必要时用 `reader_list_documents` 识别来源，不以标题猜内容。对实际相关文献分别用 `reader_search_passages`，片段不足时用 `reader_read_passage`。每个进入综合结论的来源至少要有一处直接相关证据。

按主题关系组织，区分明确共识、定义不同造成的表面相似、真正冲突、互补解释和材料空白。重要结论不能只依赖一个来源却写成多来源共识；未命中不能写成反对。输出综合结论、共同观点、分歧原因、互补关系和证据空白。
