# 重建证明

基于材料重建可逐步核查的数学证明，并显式标记模型补全和仍未解决的缺口。

1. 写出准确命题、量词、对象、假设和目标。
2. 定位使用的定义、引理或先前结果；必要时用 `reader_search_passages`，随后用 `reader_read_passage` 取得完整上下文。
3. 拆成最小有效推导步骤，每步注明依据：定义、假设、前步、定理或标准运算。
4. 保持符号一致，不偷偷加强假设，不使用待证结论。
5. 材料省略步骤时可以补全，但必须标记为“重建步骤”；无法确定就标记缺口。

输出命题、假设与符号、证明思路、分步证明、重建步骤、缺口和材料位置。不得把不确定重建写成作者原证明。
